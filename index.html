Chess Timer - Privacy Policy

Effective Date: October 30, 2026

This Privacy Policy explains how Chess Timer ("App"), published by CHALLA PRAVEEN, handles user information.

1. About the Application

Chess Timer is a chess clock application that allows users to configure timers, manage optional player profiles, and view their previous game history.

2. Optional User Profile

The user profile feature is completely optional. Users may enter their name and other profile information through the profile screen. Providing this information is not mandatory.

Profile information is stored locally on the user's device and is not uploaded to our servers.

3. Game History

The application stores game history locally on the user's device so users can review their previous chess games.

Game history is retained for a period of approximately two to four weeks, according to the application's automatic cleanup settings. Older records are automatically deleted.

When the application is uninstalled, locally stored game history and profile information are normally deleted by Android.

4. Information Collection

We do not collect or transmit the optional profile information or game history to our own servers. The application does not require an online account.

5. Information Sharing

We do not sell or share locally stored profile information or game history with third parties. If third-party services or SDKs are added in future versions, their data practices will be disclosed in an updated Privacy Policy.

6. Data Security

Profile information and game history are stored locally on the user's device. Users should protect their devices using appropriate security settings.

7. Children's Privacy

The application does not require users to provide personal information or create an account. We do not knowingly collect personal information from children.

8. Policy Updates

We may update this Privacy Policy when application features or data practices change. Updated versions will be published at this same web address.
